# Scrim effect format, v1

This is the contract shared by every Scrim host (macOS now, Linux later).
An effect written against this document must look the same on every host.

## Folder layout

```
<effect-id>/
  manifest.json          # required, described below
  *.frag                 # GLSL fragment shaders, one per pass (source)
  build/                 # generated by tools/effectc — do not edit
    <pass>.spv           # SPIR-V (Vulkan hosts)
    <pass>.metal         # Metal Shading Language (macOS host)
    <pass>.glsl          # full preprocessed GLSL 450 incl. prelude (for reading/debugging)
    <pass>.gles          # GLSL ES 3.00 (OpenGL / OpenGL ES hosts)
```

Hosts look for effects in:

| Host  | Built-in                         | User effects                                        |
|-------|----------------------------------|-----------------------------------------------------|
| macOS | `Scrim.app/Contents/Resources/effects/` | `~/Library/Application Support/Scrim/Effects/` |
| Linux | `$PREFIX/share/scrim/effects/`          | `$XDG_DATA_HOME/scrim/effects/`                 |

Hosts only read `manifest.json` and `build/`. They never compile GLSL themselves,
which keeps them small. Run `tools/effectc <effect-dir>` after editing a shader.

## manifest.json

```json
{
  "format": 1,
  "id": "rain",
  "name": "Rain",
  "version": "0.1.0",
  "passes": [
    { "shader": "background.frag", "scale": 0.5 },
    { "shader": "streaks.frag",    "scale": 0.5 },
    { "shader": "drops.frag" }
  ],
  "params": [
    { "id": "darken", "label": "Darken", "type": "float",
      "min": 0, "max": 1, "default": 0.35 }
  ]
}
```

- `format` must be `1`.
- `id`: lowercase `[a-z0-9-]+`, unique. It is used as the settings key.
- `passes`: run in order, from 1 to 8 of them.
  - `shader` is a file name in the effect folder, and its stem is used for `build/<stem>.*`.
  - `scale` is the pass's output size relative to the render size. It can be from 0.125 to 1 and defaults to 1. Lower values are cheaper and blurrier.
  - **The last pass always renders straight to the screen at full render size, and its `scale` is ignored.**
- `author`, `license`, `source` (optional strings): credits for the effect. If the
  effect folder contains `LICENSE*` or `NOTICE*` files, hosts must ship them with it.
- `params`: at most 16 of them. Each has `id` (a valid GLSL identifier), `label`, `type`, and `default`.
  - `float`: needs `min` and `max`, and is shown as a slider.
  - `bool`: shown as a toggle. The shader receives `0.0` or `1.0`.

## What every pass receives

`tools/effectc` puts a **prelude** in front of every shader. Do not write a
`#version` line or declare these yourself. Just write `void main()` and assign `fragColor`.

| Name                  | Type        | Meaning |
|-----------------------|-------------|---------|
| `vUV`                 | `vec2`      | Normalised position. **(0,0) is the top-left of the screen and +y is down.** |
| `fragColor`           | `out vec4`  | Output colour. Use non-premultiplied RGB with alpha 1. |
| `uTime`               | `float`     | Seconds of *rendered* time. It stops while the host is paused, and the host may reset it to 0 after long sessions to keep precision, so avoid one-off events tied to absolute time. |
| `uFrame`              | `float`     | Frame counter. |
| `uDelta`              | `float`     | Seconds since the previous frame. |
| `uWallpaperLevels`    | `float`     | Number of mip levels in `uWallpaper`. |
| `uResolution`         | `vec2`      | Size of *this pass's* output, in pixels. |
| `uTexel`              | `vec2`      | `1.0 / uResolution`. |
| `uScreenSize`         | `vec2`      | Full render size in pixels (the last pass's size). |
| `uWallpaperSize`      | `vec2`      | Wallpaper texture size in pixels. |
| `uWallpaper`          | `sampler2D` | The user's wallpaper as it is, not aspect-corrected. Use `wallpaperUV()`. Has a **full mip chain**, so `textureLod(uWallpaper, uv, lod)` gives a cheap blur (each level halves the resolution). |
| `uPrevious`           | `sampler2D` | Output of the previous pass. For pass 0, this is the wallpaper. Sample it with `vUV` directly. |
| `p_<id>`              | `float`     | Each manifest param, as a `#define`. |

Helpers in the prelude:

- `vec2 wallpaperUV(vec2 uv)` converts a screen uv into a wallpaper uv with aspect-fill, matching how macOS shows wallpapers by default.
- `float aspect()` returns `uScreenSize.x / uScreenSize.y`.
- `float hash11(float)`, `float hash12(vec2)`, `vec2 hash22(vec2)`, `vec3 hash31(float)` are cheap, deterministic hashes that return values from 0 to 1.
- `mat2 rot2(float a)` builds a 2D rotation matrix.
- `vec4 textureLodSmooth(sampler2D, vec2 uv, float lod)` works like `textureLod`, but uses a smooth
  (cubic B-spline) filter above lod 1, so large blurs don't look like an upscaled low-res image.
  It costs up to 8 texture fetches instead of 1. Use it on `uWallpaper`.
- `vec4 textureBicubicLevel(sampler2D, vec2 uv, int level)` is the single-level version.

Rules:

- Do not use `gl_FragCoord`. Its origin differs between APIs, so use `vUV * uResolution`.
- Never call `smoothstep(a, b, x)` with `a >= b`, including `a == b == 0`. GLSL leaves
  that undefined: Metal happens to return something sensible, but Mesa doesn't. For a
  falling edge write `1.0 - smoothstep(b, a, x)`, and skip zero-size shapes explicitly.
- Every texture sample uses a trilinear filter (linear, with linear blending between mip levels) that clamps at the edges.
  `uPrevious` has no mipmaps, so `textureLod` on it always reads level 0.
- Colour values are gamma-encoded sRGB in both directions, so don't convert to or from linear light.
- Effects are stateless in v1. They cannot read their own output from the last frame.

## Host binary contract (for host authors)

The prelude declares:

```glsl
layout(set = 0, binding = 0, std140) uniform Host {
    vec4 uTimeFrame;   // x = time, y = frame, z = delta, w = wallpaper mip level count
    vec4 uRes;         // xy = pass resolution, zw = 1 / resolution
    vec4 uSizes;       // xy = screen size, zw = wallpaper size
    vec4 uParams[16];  // .x = param value, in manifest order
};
layout(set = 0, binding = 1) uniform sampler2D uWallpaper;
layout(set = 0, binding = 2) uniform sampler2D uPrevious;
layout(location = 0) in  vec2 vUV;
layout(location = 0) out vec4 fragColor;
```

The uniform block is 304 bytes. Hosts draw one full-screen triangle and provide
`vUV` at location 0, oriented as described above.

- Metal: the fragment function is `main0`. The block goes in `[[buffer(0)]]`, `uWallpaper` in `[[texture(1)]]` / `[[sampler(1)]]`, and `uPrevious` in `[[texture(2)]]` / `[[sampler(2)]]`. The vertex output must declare `float2 vUV [[user(locn0)]]`.
- Vulkan: descriptor set 0 with the bindings above.
- OpenGL ES 3 / GL: load `build/<pass>.gles`. GLSL ES 3.00 has no binding qualifiers, so bind
  the uniform block `Host` and the samplers `uWallpaper` / `uPrevious` by name. The vertex
  shader outputs `vUV`. GL framebuffers are bottom-up, so when a pass renders into a texture
  that a later pass samples, flip the triangle vertically. Then `texture(uPrevious, vUV)`
  reads the same screen position. Upload images top row first.
